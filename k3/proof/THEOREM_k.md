## 1. Costs and lifts
For d ∈ D let κ(d) = min{a + b : a, b ∈ M, a − b = d}, with witnesses (α_d, β_d) attaining it, chosen so that
α_{−d} = β_d, β_{−d} = α_d, α_0 = β_0 = 0 (so κ(−d) = κ(d), κ(0) = 0). Put κ(d) = +∞ for d ∉ D.
For r ∈ Z/QZ let
  c_k(r) = min{ Σ_{i<k} κ(d_i) : (d_0,…,d_{k−1}) ∈ D^k, Σ_{i<k} d_i q^i ≡ r (mod Q) }.

**Lemma 0 (carry automaton = true minimum).** Write r = Σ_{i<k} r_i q^i with digits r_i ∈ [0, q). Then
  c_k(r) = min_{(g_1,…,g_k) ∈ {0,−1}^k} Σ_{i<k} κ(r_i − g_i + q g_{i+1}),   g_0 := 0,
and the minimising vectors of the two sides correspond via d_i = r_i − g_i + q g_{i+1}.

*Proof.* (⊇) If g ∈ {0,−1}^k and all d_i := r_i − g_i + q g_{i+1} lie in D, then Σ d_i q^i = Σ r_i q^i + g_k q^k
(the sum telescopes: Σ_i (q g_{i+1} − g_i) q^i = g_k q^k − g_0), so (d_i) is admissible; the cost is the same.
(⊆) Let (d_i) ∈ D^k be admissible and E_i := Σ_{j<i} (d_j − r_j) q^j for 0 ≤ i ≤ k. Reducing Σ_{j<k} d_j q^j ≡ r (mod q^k)
modulo q^i gives q^i | E_i. Since d_j ∈ [−B, B] and r_j ∈ [0, q−1] we have −(B+q−1) ≤ d_j − r_j ≤ B, hence
  −2(q^i − 1) < −(B+q−1)(q^i − 1)/(q − 1) ≤ E_i ≤ B(q^i − 1)/(q − 1) < q^i   (using B < q, so (B+q−1)/(q−1) < 2).
A multiple of q^i in (−2q^i, q^i) is 0 or −q^i, so g_i := E_i/q^i ∈ {0, −1} for 1 ≤ i ≤ k, and g_0 = 0.
From E_{i+1} = E_i + (d_i − r_i) q^i we get d_i = r_i − g_i + q g_{i+1}. ∎

So c_k is the min-plus value of a path of length k through the 2-state carry automaton with edge weights
κ(r_i − g_i + q g_{i+1}); off-D digits have weight +∞. For k = 3 this gives the two factorisations used by the
builders (both exact, by Lemma 0 applied to k = 3 and, inside B, to k = 2):
- (A, low-heavy) c_3(r) = min_{g∈{0,−1}} [ A_g(r_0, r_1) + T_g(r_2) ], with
  A_g(r_0,r_1) = min_{g_1} κ(r_0 + q g_1) + κ(r_1 − g_1 + q g), T_g(r_2) = min_{g_3} κ(r_2 − g + q g_3);
- (B, top-heavy) c_3(r_0 + qR) = min( κ(r_0) + c_2[R], κ(r_0 − q) + c_2[(R+1) mod q²] ), R ∈ [0, q²),
  where c_2 is computed directly from its definition (min over D×D).
Every residue is attainable (all Q residues covered) for k = 2, 3. Since c_k(−r) = c_k(r) (negate a lift), every
cost class except those containing 0 and h has even size; conversely the odd classes are exactly {c(0)=0, c(h)}.

**Lifts.** Fix one representative r of every orbit {r, −r} with r ∉ {0, h}, choose a min-cost vector

e(r) ≡ r (mod Q), e(−r) = −e(r), and e is a *function of the residue* (h is never used since N_h = 0).
u-block (α_{d_0},…,α_{d_{k−1}}), v-block (β_{d_0},…,β_{d_{k−1}}); their difference has value e(r).

## 3. Lemmas (identical to the k = 2 note with 2 → k)
**A (encoding lands in U).** For a word w ∈ (Z/QZ)^ℓ of the type: u(w) = Σ_i (Σ_j α_{d_j(w_i)} q^j) Q^i,
v(w) likewise with β. All base-q digits lie in M (≤ B < q, no carries). r and −r occur equally often and the
realisation of −r is the swap of that of r, so digit-sum(u) = digit-sum(v) = Σ_{orbits} N_r c_k(r) = C/2 = L.
Hence u, v ∈ U and u − v = Σ_i e(w_i) Q^i.
**B (injectivity).** Δ(w) = Σ_i e(w_i) Q^i determines w: Δ mod Q = w_0, then (Δ − e(w_0))/Q = Δ(w_1 w_2 …); induct.
Hence |U − U| ≥ 𝓜 := ℓ!/(N_0! Π_{r≠0,h} N_r!).
**C (sumset).** U + U ⊆ { Σ_{j<kℓ} s_j q^j : s_j ∈ M+M, Σ s_j ≤ C }, so for 0 < x < 1,
|U+U| ≤ x^{−C} P₊(x)^{kℓ}, P₊(x) = Σ_{s∈M+M} x^s.
**D (GHR with V = 2U).** [GHR2007] as quoted on the 3a page: finite V ⊂ Z_{≥0}, 0 ∈ V, |V−V| < 2maxV+1 ⇒
C_{3a} ≥ 1 + log(|V−V|/|V+V|)/log(2maxV+1). With V = 2U: |V−V| = |U−U| ≤ 2maxU+1 < 2maxV+1, |V+V| = |U+U|,
maxU ≤ B(q^{kℓ}−1)/(q−1), so log(2maxV+1) ≤ log(4B q^{kℓ}/(q−1) + 1).
